# DAY 2 - STRINGS

## Theory

- String is a sequence of characters.
- String index starts from 0.
- length() returns total characters.
- charAt(index) returns a character.
- equals() compares strings.
- toUpperCase() converts to uppercase.
- toLowerCase() converts to lowercase.

## Interview Questions

Q: What is a String?

A: String is a sequence of characters.

Q: How do you find String length?

A: str.length()

Q: How do you access a character?

A: str.charAt(index)

Q: How do you compare two Strings?

A: str.equals(otherString)

Q: What exception occurs for invalid index?

A: StringIndexOutOfBoundsException
