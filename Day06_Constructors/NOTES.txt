CONSTRUCTORS

What is a Constructor?

A constructor is a special method used to initialize objects.

It is automatically called when an object is created.

Why Do We Need Constructors?

Without Constructor:

Create Object
Assign Values

With Constructor:

Create Object + Assign Values Together

Example:

Student s = new Student("Kavya",22);

Characteristics Of A Constructor

1. Constructor name must be same as class name.
2. Constructor has no return type.
3. Constructor is automatically called.
4. Constructor is used to initialize objects.

Types Of Constructors

1. Default Constructor

Example:

Student(){

}

2. Parameterized Constructor

Example:

Student(String name,int age){

}

this Keyword

this refers to the current object.

Example:

this.name = name;
this.age = age;

Constructor Vs Method

Constructor:
- Same name as class
- No return type
- Automatically called

Method:
- Can have any name
- Has return type or void
- Called explicitly

Advantages

1. Initializes objects
2. Cleaner code
3. Better readability
4. Reduces repeated assignments
